[overview]
sentai - Coral Dev Board Micro Python Runtime
==============================================
  sentai.help()          Show this help
  sentai.help('tpu')     Help for a specific sub-module
  sentai.help('serial')  UART/USB raw serial vs Meshtastic
  sentai.help('all')     Show all documentation
  sentai.run(path)       Execute a .py script from flash
  sentai.console(target) Set REPL target: 'usb' or 'uart'

  sentai.rtos     FreeRTOS system info
  sentai.tpu      EdgeTPU inference
  sentai.fs       Filesystem (LittleFS)
  sentai.camera   Camera capture

  sentai.uart     UART serial I/O

  sentai.link     MAVLink telemetry bridge

  sentai.aifes    On-device neural network training (AIfES)

[tpu]
sentai.tpu - EdgeTPU inference
==============================
  load(path)            Load .tflite model from flash
  load_image(path)      Load image into input tensor
  invoke()              Run inference -> ms elapsed (-1=not ready)
  ready()               True if model & interpreter ready
  num_outputs()         Number of output tensors
  output_size(idx)      Byte size of output tensor idx
  output(idx)           Raw bytes of output tensor idx
  output_dims(idx)      Shape tuple, e.g. (1, 1344, 5)
  output_type(idx)      TfLiteType (3=uint8, 9=int8, 2=int32)
  row(idx, r)           Tuple of values at row r
  val(idx, flat_i)      Single value at flat index
  save_output(path)     Save all outputs to CSV file
  input_quant()         Input quantization -> (scale, zero_point)
  output_quant(idx)     Output quantization -> (scale, zero_point)
  output_floats(idx)    Output tensor as list of floats (dequantized).
                        Auto-dequantizes int8/uint8 using scale/zero_point.
                        For float32 tensors, returns values directly.
                        Useful for feeding TPU features to AIfES.
  input_type()          Input TfLiteType (9=int8, 3=uint8, 1=float)

  --- YOLO detection post-processing ---
  detect(conf=0.25, iou=0.45, max=50)
                        Run NMS on last invoke() output.
                        conf/iou are float 0.0-1.0 (0.25 = 25%).
                        Returns list of (x1,y1,x2,y2,conf,class_id).
                        conf is float 0.0-1.0. Coords in model pixels.
  draw(path, [dets], [quality=75])
                        Draw bounding boxes + class labels on the last
                        to_tensor() frame and save as JPEG.
                        If dets omitted, runs detect() automatically.
                        Returns number of detections drawn.

  Example (YOLO detection pipeline):
    sentai.tpu.load('/models/yolov8n.tflite')
    sentai.camera.init()
    sentai.camera.to_tensor()
    sentai.tpu.invoke()
    dets = sentai.tpu.detect(0.25)
    for d in dets:
        print(d)                    # (x1,y1,x2,y2,0.87,0)
    sentai.tpu.draw('/det.jpg', dets)

[imu]
sentai.imu - LIS2DU12 accelerometer
======================================
  On-board 3-axis accelerometer (I2C5, addr 0x19).
  Returns native float values.

  init()      Initialize sensor. Returns 0=ok, -1=fail.
              Safe to call multiple times (no-op if already init).
  read()      Read acceleration + temperature -> dict or None
              Returns: {x, y, z, temp}
                x,y,z  = milli-g (float, mg)
                         At rest z-up: x~0.0, y~0.0, z~981.0
                temp   = degrees C (float, e.g. 25.3)
              Returns None if data not ready.

  Example:
    sentai.imu.init()
    d = sentai.imu.read()
    if d:
        print('x:', d['x'], 'y:', d['y'], 'z:', d['z'])
        print('temp:', d['temp'], 'mC')

[mic]
sentai.mic - PDM microphone recording
=======================================
  On-board PDM microphone. Records 16-bit mono PCM at 16 kHz.
  Background FreeRTOS task records into a ring buffer (last N seconds).
  Max ring size: 10 seconds (160 000 samples, 320 KB).
  Recording never stops — always keeps the last N seconds of audio.
  Files saved to /audio/recNNN.mp3 with auto-incrementing counter.

  start(seconds=10) Start ring recording (1-10s ring). Returns 0=ok.
  stop()            Stop mic entirely. Returns number of samples in ring.
  busy()            True if mic is running.
  samples()         Number of samples available in ring.
  level()           Current RMS level in centi-dB (e.g. 4500 = 45.00 dB).
                    Auto-starts mic in monitor mode if not running.
  save_l3()         Save ring buffer as MP3 (64 kbps, shine encoder).
                    Can be called while recording — pauses briefly, resumes.
                    Returns filename str or None.

  Example:
    sentai.mic.start()              # start ring recording (10s)
    sentai.rtos.sleep_ms(5000)      # let it record for a while
    f = sentai.mic.save_l3()        # save last 5s as MP3
    print('saved:', f)              # recording continues!
    sentai.rtos.sleep_ms(10000)     # record more
    f = sentai.mic.save_l3()        # save last 10s as MP3
    sentai.mic.stop()               # done

[mesh]
sentai.mesh - Meshtastic mesh radio bridge
==========================================
  Communicates with a Meshtastic device (e.g. WisMesh Pocket/Tap)
  over UART using the Meshtastic serial protobuf protocol.
  Requires REPL on USB (default) — UART is used for the radio link.

  init(baud=38400)      Open UART, start RX task, connect to radio
  stop()                Stop RX task, close UART
  node()                Our node number (set after init/config)
  config()              Request config/NodeDB from radio

  --- Text messages ---
  send(text, dest=0xFFFFFFFF, ch=0, ack=0)
                        Send text to mesh (broadcast by default)
  available()           Number of received text messages queued
  receive(timeout=0)    Get next text msg -> dict or None
                        timeout: 0=poll, -1=block, >0=ms
    Returns: {from, to, text, id, rssi, snr, channel, hop_limit}
    snr is integer x100 (e.g. 650 = 6.50 dB)

  --- Vision messages (PRIVATE_APP portnum 256) ---
  send_detection(sensor_id, track_id, alarm_type, timestamp, seq,
                 x, y, w, h, conf, class_id, embedding, crc8,
                 [dest=0xFFFFFFFF, ch=0, ack=0])
  send_update(sensor_id, track_id, alarm_type, timestamp, seq,
              x, y, w, h, conf, age,
              [dest=0xFFFFFFFF, ch=0, ack=0])
  vision_available()    Number of received VisionMessages queued
  receive_vision(timeout=0)  Get next vision msg -> dict or None
    Returns: {from, to, id, rssi, snr, channel, sensor_id,
              track_id, alarm_type, timestamp, seq, type,
              x, y, w, h, conf, ...}
    type: 'new' (+ class_id, embedding, crc8)
          'update' (+ age)

  Protocol details (Meshtastic serial):
    Header: 0x94 0xC3 <len_msb> <len_lsb>
    Payload: protobuf-encoded ToRadio (host->radio)
             or FromRadio (radio->host)
    Max payload: 512 bytes

  Startup sequence (done automatically by init):
    1. Open UART at baud rate (default 38400)
    2. Start FreeRTOS RX task (reads frames, decodes protobuf)
    3. Call config() to request NodeDB (want_config_id=1)
    4. Radio replies with MyNodeInfo, Config, ..., ConfigCompleteId
    5. my_node_num is stored; radio is ready

  Example:
    sentai.mesh.init()                  # connect to radio
    sentai.mesh.send('hello world')     # broadcast text
    sentai.mesh.send('hi', 0x12345678)  # send to specific node
    while True:
        msg = sentai.mesh.receive(5000) # wait 5s for text
        if msg:
            print(msg['from'], msg['text'])

[serial]
sentai.uart / sentai.usb - Raw serial I/O (no Meshtastic)
=========================================================
  Use these when you want plain serial read/write without
  any Meshtastic framing or protobuf. Choose UART or USB
  depending on which one is NOT used for the REPL.

  --- UART serial (when REPL is on USB, which is the default) ---
    sentai.uart.open(38400)              # open UART @ baudrate
    sentai.uart.write(b'AT\r\n')         # send raw bytes
    resp = sentai.uart.read(256, 1000)   # read up to 256 bytes, 1s timeout
    n = sentai.uart.available()           # bytes waiting
    sentai.uart.close()

  --- USB serial (when REPL is on UART) ---
    sentai.console('uart')               # move REPL to UART first
    sentai.usb.open()                    # open USB CDC ACM
    sentai.usb.write(b'hello')           # send to USB host
    data = sentai.usb.read(256, 1000)
    sentai.usb.close()

  --- UART vs Mesh: what's the difference? ---
    sentai.uart  = raw bytes in, raw bytes out. No framing.
                   You send/receive exactly what you write/read.
    sentai.mesh  = Meshtastic protocol. Wraps your data in
                   protobuf (ToRadio/FromRadio), adds 4-byte
                   header. The radio handles routing, encryption,
                   and LoRa transmission over the mesh network.

  To talk to a Meshtastic radio: use sentai.mesh
  To talk to a GPS, sensor, or any other UART device: use sentai.uart
  To exchange data with a PC over USB: use sentai.usb

[link]
sentai.link - MAVLink v2 telemetry bridge
=========================================
  Communicates with a MAVLink autopilot / GCS over UART using
  the official MAVLink v2 protocol (c_library_v2).
  Requires REPL on USB (default) — UART is used for the MAVLink link.
  Cannot run simultaneously with sentai.mesh (same UART).

  init(baud=57600, sysid=1, compid=191)
                        Open UART, start RX task (MAVLink parser)
                        compid 191 = MAV_COMP_ID_ONBOARD_COMPUTER
  stop()                Stop RX task, close UART

  --- Receiving ---
  available()           Number of received MAVLink messages queued
  receive(timeout=0)    Get next msg -> dict or None
                        timeout: 0=poll, -1=block, >0=ms
    Returns: {msgid, sysid, compid, seq, len, ...}
    msgid: MAVLink message ID (0=HEARTBEAT, 1=SYS_STATUS,
           24=GPS_RAW_INT, 30=ATTITUDE, 32=LOCAL_POSITION_NED,
           33=GLOBAL_POSITION_INT, 253=STATUSTEXT, etc.)

    Decoded messages (extra fields added automatically):

    msgid 32 — LOCAL_POSITION_NED:
      time  (uint32, ms since boot)
      x, y, z       (float, metres)
      vx, vy, vz    (float, m/s)

    msgid 33 — GLOBAL_POSITION_INT:
      time      (uint32, ms since boot)
      lat, lon  (int32, degrees * 1e7)
      alt       (int32, mm above MSL)
      rel_alt   (int32, mm above home)
      vx,vy,vz  (int16, cm/s)
      hdg       (uint16, heading in cdeg, 0..35999)

  --- Sending ---
  heartbeat(type=18)    Send HEARTBEAT (18=onboard controller)
  send(text, sev=6)     Send STATUSTEXT (sev: 0-7, 6=INFO)
  command(tsys, tcomp, cmd, [conf, p1..p7])
                        Send COMMAND_LONG (params are float)

  --- Vision over MAVLink (base64 STATUSTEXT chunks) ---
  send_detection(sensor_id, track_id, alarm_type, timestamp, seq,
                 x, y, w, h, conf, class_id,
                 [embedding, crc8, severity=6])
  send_update(sensor_id, track_id, alarm_type, timestamp, seq,
              x, y, w, h, conf, age, [severity=6])

  VisionMessage is nanopb-encoded, base64-encoded, then split into
  50-char STATUSTEXT chunks with id + chunk_seq for reassembly.

  Example:
    sentai.link.init(57600)          # connect to autopilot
    sentai.link.heartbeat()          # send heartbeat
    sentai.link.send('Hello GCS')    # send status text
    while True:
        msg = sentai.link.receive(5000)
        if msg:
            if msg['msgid'] == 33:   # GLOBAL_POSITION_INT
                print('lat:', msg['lat'], 'lon:', msg['lon'])
            elif msg['msgid'] == 32: # LOCAL_POSITION_NED
                print('x:', msg['x'], 'y:', msg['y'], 'z:', msg['z'])
            else:
                print(msg['msgid'], msg['sysid'])

[crazy]
sentai.crazy - CrazyFlie autopilot bridge (CRTP over CPX over UART)
=================================================================
  Sends CRTP commands to a CrazyFlie drone through the CPX
  protocol over UART. A dedicated FreeRTOS task sends Commander
  setpoints at 50 Hz for attitude-stabilized flight.
  Requires REPL on USB — UART is used for the CPX link.
  Cannot run simultaneously with sentai.mesh or sentai.link.

  init(baud=576000)     Open UART, start CPX RX + CMD tasks
  stop()                Stop all tasks, close UART
  debug(level)          0=off, 1=summary, 2=+hex dump
  arm()                 Arm the drone (manual — fly/attitude auto-arm)
  disarm()              Disarm (manual — fly/fly_stop auto-disarm)
  ping(timeout=1000)    CRTP echo ping -> round-trip ms (>0)
                        Returns -1=not running, -2=send fail,
                        -3=timeout (drone not responding).

  --- Attitude-stabilized flight (IMU only, no flow deck!) ---
  A FreeRTOS CMD task sends CRTP Commander at 50 Hz for attitude().
  fly() uses HL Commander with Kalman estimator + barometer for
  altitude hold — no continuous sending needed.
  Watchdog: CF cuts motors if no setpoint for 500ms (warning)
  or 2s (lock+reboot). HL Commander feeds it internally.

  fly(height=0.5, hold_ms=2000, takeoff_ms=3000, land_ms=3000)
                        Blocking HL Commander flight cycle:
                        arm → takeoff → hold → land → disarm.
                        Uses barometer for altitude hold.
                        height: metres above takeoff point.
                        hold_ms: time to hold at altitude (ms).
                        takeoff_ms/land_ms: ramp duration (ms).
                        Returns 0=ok, -2=busy, -3=arm fail,
                        -4=takeoff fail, -5=aborted.

  attitude(roll=0, pitch=0, yaw_rate=0, thrust=0)
                        Non-blocking: set Commander setpoint.
                        CMD task sends it at 50 Hz automatically.
                        Auto-arms on first call.
                        roll/pitch: degrees, yaw_rate: deg/s.
                        thrust: 0-65535 raw.
                        Use fly_stop() to land and disarm.
                        Returns 0=ok, -2=auto fly in progress.

  fly_stop()            Stop flying and disarm. Non-blocking.
                        Sends zero thrust, then disarms.
                        Safe to call from any state.

  --- High-Level Commander (uses Kalman estimator + barometer) ---
  takeoff(h=0.5, dur=2.0, yaw=0, use_yaw=1, group=0)
                        Take off to h metres over dur seconds
  land(h=0.0, dur=2.0, yaw=0, use_yaw=1, group=0)
                        Land to h metres over dur seconds
  stop_motors(group=0)  Emergency stop — all motors off
  go_to(x, y, z, yaw=0, dur=3.0, rel=1, lin=0, group=0)
                        Go to position (metres). rel=1 relative.

  --- Velocity hover (uses Kalman estimator + barometer) ---
  hover(vx=0, vy=0, yr=0, z=0.5)
                        vx,vy: m/s  yr: deg/s  z: metres
                        MUST be called in a loop! Safety watchdog
                        cuts motors if hover stops for ~1 second.

  --- Motor test (motorPowerSet params, like cflib) ---
  test_fly(power=6553, dur_ms=2000)
                        Direct motor test via CRTP param system.
                        Sets motorPowerSet.m1-m4 to power, enable=1,
                        waits dur_ms, then stops. Bypasses Commander,
                        arming, and position estimator entirely.
                        power: 0-65535 (10%=6553, 20%=13107).
                        First call scans param TOC (~1-2s).
                        Returns 0=ok, -1=not running, -2=TOC fail.

  --- Raw CRTP ---
  send_crtp(port, ch, data)
                        Send arbitrary CRTP packet (max 30 bytes)

  Example (HL Commander altitude-hold flight):
    sentai.crazy.init()
    sentai.crazy.debug(1)
    sentai.crazy.fly()                     # 50cm, hold 2s (defaults)
    sentai.crazy.fly(0.3, 3000)            # 30cm, hold 3s
    sentai.crazy.fly(1.0, 5000, 3000, 3000)# 1m, hold 5s, slow ramp
    sentai.crazy.stop()

  Example (manual attitude control from Python):
    sentai.crazy.init()
    sentai.crazy.attitude(0, 0, 0, 35000)  # auto-arms, starts 50Hz
    sentai.rtos.sleep_ms(2000)             # fly level for 2s
    sentai.crazy.attitude(5, 0, 0, 35000)  # tilt 5° right
    sentai.rtos.sleep_ms(1000)
    sentai.crazy.fly_stop()                # ramp down + disarm
    sentai.crazy.stop()

  Example (check if drone is alive):
    sentai.crazy.init()
    ms = sentai.crazy.ping()
    if ms > 0:
        print('Drone OK, RTT:', ms, 'ms')
    else:
        print('No response from drone')

  Example (motor test — raw, no stabilization):
    sentai.crazy.init()
    sentai.crazy.debug(1)
    sentai.crazy.test_fly(6553, 1000)      # 10% power, 1s
    sentai.crazy.stop()

  Example (HL commander — needs flow deck!):
    sentai.crazy.init(576000)
    sentai.crazy.arm()
    sentai.crazy.takeoff(0.5, 2.0)
    sentai.rtos.sleep_ms(3000)
    sentai.crazy.land(0.0, 2.0)
    sentai.crazy.stop()

[pipeline]
sentai.pipeline - Continuous detection pipeline + SentAI-SORT tracker
=====================================================================
  Runs YOLO detection continuously in a background FreeRTOS task.
  Optionally enables SentAI-SORT multi-object tracking with:
    - 8-state Kalman filter (constant-velocity, block-diagonal P)
    - ByteTrack two-stage greedy association (high + low confidence)
    - HSV color histogram (4x4 grid, 8 bins = 128D, Bhattacharyya)
    - IMU camera motion compensation (pitch/roll delta → pixel shift)
    - Ground-plane projection (4-corner ray-cast, trapezoid-aware)
    - GPS coordinate output (flat-earth approximation)
  All state is static — zero heap allocation. ~14 KB SDRAM.

  --- Pipeline control ---
  start([conf, iou, max, track])
                        Start detection pipeline.
                        conf/iou: float 0.0-1.0 (default 0.5/0.45)
                        max: int max detections (default 50)
                        track: bool enable tracker (default False)
                        Returns 0 on success.
  stop()                Stop pipeline and disable tracker.
  running()             True if pipeline is running.
  get([timeout_ms])     Get detection frame -> list of tuples or None
                        Each tuple: (x1,y1,x2,y2,conf,class_id)
                        timeout default 1000ms.
  stats()               Pipeline stats -> (processed, dropped, fps)

  --- Tracker output ---
  tracks()              Snapshot of active tracks -> list of tuples
                        (id, x1,y1,x2,y2, conf, class_id, state,
                         hits, age, gx_cm, gy_cm, dist_cm, width_cm,
                         lat, lon)
                        state: 1=confirmed, 2=lost
                        gx_cm/gy_cm: ground position (East/North cm)
                        dist_cm: distance from nadir
                        lat/lon: GPS coords (0.0 if no GPS set)
  event([timeout_ms])   Next track event -> tuple or None
                        (type, id, x1,y1,x2,y2, conf, class_id,
                         frame_seq, gx_cm, gy_cm, dist_cm, lat, lon)
                        type: 1=new, 2=update, 3=lost, 4=removed

  --- Tracker configuration ---
  track_config([min_hits, max_misses, iou, hist, high, low])
                        Get/set tracker params. Returns current config.
                        min_hits: frames to confirm (default 3)
                        max_misses: frames to remove (default 5)
                        iou: min IoU threshold 0.0-1.0 (default 0.3)
                        hist: histogram weight 0.0-1.0 (default 0.3)
                        high: high-conf threshold (default 0.5)
                        low: low-conf threshold (default 0.1)

  --- Sensor pose (ground projection) ---
  set_pose(altitude_cm [, heading_deg [, lat, lon]])
                        Set camera pose for ground projection.
                        altitude_cm: height above ground (0=disable)
                        heading_deg: compass 0=N,90=E,-1=no compass
                        lat/lon: camera GPS in degrees (0.0=no GPS)

  --- Per-camera geometry ---
  camera_config(cam_id [, fov_h, fov_v, mount_pitch, mount_roll, mount_yaw])
                        Get/set camera mount configuration.
                        cam_id: 0 or 1 (matches camera.switch id)
                        fov_h/fov_v: field of view degrees (70.8/43.4)
                        mount_pitch: tilt from vertical in degrees
                          0 = straight down (perpendicular to ground)
                          25 = tilted 25 deg from vertical (forward)
                          90 = looking at horizon
                        mount_roll: sensor rotation
                          0 = landscape, 90 = portrait CW
                        mount_yaw: heading offset from board forward
                          0 = forward, 180 = backward
                        Returns (fov_h, fov_v, pitch, roll, yaw).

                        Ground projection uses 4-corner ray-cast:
                        each bbox corner is projected as a 3D ray
                        through the pinhole camera model, rotated by
                        mount angles + IMU, and intersected with the
                        ground plane. At non-zero pitch the image
                        footprint is a trapezoid (far edge wider).

  NOTE: Cross-camera track handoff is NOT currently supported.
  When camera.switch() is called, existing tracks will time out
  and new tracks will be created from the new camera's detections.
  Matching is done in pixel space (IoU + histogram), not ground
  coordinates, so a target visible in both cameras gets separate
  track IDs. Future: ground-to-pixel re-projection at switch time.

  Example (tracking with ground projection):
    sentai.camera.init()
    # Camera 0: straight down
    sentai.pipeline.camera_config(0, 70.8, 43.4, 0, 0, 0)
    # Camera 1: 25 deg tilt, facing backward
    sentai.pipeline.camera_config(1, 70.8, 43.4, 25, 0, 180)
    # Set altitude and heading
    sentai.pipeline.set_pose(1000, 0, 44.4268, 26.1025)
    # Start with tracking
    sentai.pipeline.start(0.3, 0.45, 50, True)
    while True:
        evt = sentai.pipeline.event(2000)
        if evt:
            typ, tid = evt[0], evt[1]

            if typ == 1:

[aifes]
sentai.aifes - On-device Neural Network Training (AIfES)
========================================================
  Train and run feedforward neural networks directly on the MCU.
  Uses AIfES library from Fraunhofer IMS (AGPL-3.0 license).
  Supports fully-connected layers with various activations.

  --- Model loading ---
  load(path) -> bool    Load model architecture from YAML file.
                        Returns True on success.
  load_weights(path) -> bool
                        Load pre-trained weights from binary file.
  save_weights(path) -> bool
                        Save trained weights (best validation model).
  unload()              Unload model and free memory.
  ready() -> bool       Check if model is loaded and ready.

  --- Training ---
  train(x_data, y_data, epochs=100, batch=4, lr=0.01,
        optimizer=ADAM, loss=MSE, val_split=0.1, log_path=None,
        sigreg=0.0)
                        Train model on provided data.
                        x_data: list of input samples [[f,f,...],...]
                        y_data: list of target samples [[f,f,...],...]
                        epochs: training iterations (default 100)
                        batch: mini-batch size (default 4)
                        lr: learning rate (default 0.01)
                        optimizer: ADAM (0) or SGD (1)
                        loss: MSE (0) or CROSSENTROPY (1)
                        val_split: validation fraction 0-1 (default 0.1)
                        log_path: save training log to file (optional)
                        sigreg: Weak-SIGReg covariance regularization lambda.
                               0 = disabled (default), 0.001-0.1 typical.
                               Based on arXiv:2603.05924
                               Decorrelates hidden layer activations for
                               stable training and better generalization.
                               Which layers get SIGReg is configured per-layer
                               in the YAML model file (see below).
                        Returns final loss, or -1 on error.

  --- Inference (new TPU-style API) ---
  set_input(data) -> int
                        Set input data from list of floats.
                        Returns 0 on success, negative on error.
  from_tpu(idx) -> int  Set input from TPU output tensor idx.
                        Auto-dequantizes int8/uint8 to float.
                        Returns 0 on success, negative on error.
  from_camera(w, h, gray=False) -> int
                        Capture camera, resize to w×h, normalize [0,1].
                        gray=False: RGB, w*h*3 floats. gray=True: w*h floats.
                        Camera must be initialized first.
                        Returns 0 on success, negative on error.
  from_mic(samples) -> int
                        Capture mic samples, normalize [-1,1].
                        Microphone must be initialized with mic_init().
                        Returns 0 on success, negative on error.
  invoke() -> int       Run inference using previously set input.
                        Returns inference time in ms, or negative on error.
  output() -> list      Get output from last inference as list of floats.

  --- Microphone control ---
  mic_init() -> int     Initialize microphone at 16kHz. Returns 0 on success.
  mic_stop() -> int     Stop microphone. Returns 0 on success.

  predict(input) -> list
                        (Legacy) Run inference on single input sample.
                        Equivalent to: set_input(input); invoke(); output()

  --- Model info ---
  info() -> dict        Get model information:
                        {'name': str, 'layers': int, 'input_size': int,
                         'output_size': int, 'params': int, 'best_epoch': int}

  --- Constants ---
  ADAM = 0              Adam optimizer (adaptive learning rate)
  SGD = 1               Stochastic Gradient Descent
  MSE = 0               Mean Squared Error loss
  CROSSENTROPY = 1      Cross-entropy loss (for classification)

  --- YAML model format ---
  Model architectures are defined in YAML files:
    model:
      name: xor_net
    backbone:
      - [input, 2]
      - [dense, 4, relu]
    head:
      - [dense, 1, sigmoid]
    train:
      epochs: 100
      lr: 0.01
      sigreg: 0.01           # Global SIGReg lambda (optional)

  SIGReg per-layer configuration:
    backbone:
      - [input, 128]
      - [dense, 64, relu, sigreg]    # SIGReg ON for this layer
      - [dense, 32, relu]            # SIGReg OFF (default)
      - [dense, 10, softmax]
    
    Priority:
    1. YAML per-layer "sigreg" flag (highest)
    2. train.sigreg_layers array from YAML or Python
    3. If no YAML flags set, applies to all hidden layers

  Supported layers: dense
  Supported activations: relu, sigmoid, tanh, softmax, leaky_relu,
                         elu, softsign, linear

  Example (XOR problem):
    x = [[0,0], [0,1], [1,0], [1,1]]
    y = [[0], [1], [1], [0]]
    
    sentai.aifes.load('/models/xor.yaml')
    loss = sentai.aifes.train(x, y, epochs=500, lr=0.1)
    
    # Inference (new style)
    sentai.aifes.set_input([0, 1])
    sentai.aifes.invoke()
    print(sentai.aifes.output())  # [0.98]
    
    sentai.aifes.save_weights('/models/xor_weights.bin')

  Example (transfer learning: TPU backbone + AIfES head):
    # Use MobileNet as frozen feature extractor
    sentai.tpu.load('/models/mobilenet_features.tflite')
    sentai.aifes.load('/models/classifier_head.yaml')
    sentai.camera.init()
    
    # Collect training samples (3 classes, 5 samples each)
    x_train, y_train = [], []
    for label in range(3):
        print(f'Show class {label}, collect 5 samples')
        for _ in range(5):
            input('Press Enter...')
            sentai.camera.to_tensor()
            sentai.tpu.invoke()
            x_train.append(sentai.tpu.output_floats(0))  # features
            y_train.append([1 if i==label else 0 for i in range(3)])
    
    # Train classifier head on device
    loss = sentai.aifes.train(x_train, y_train, epochs=200, lr=0.01)
    sentai.aifes.save_weights('/models/my_classifier.bin')
    
    # Inference loop (new API)
    while True:
        sentai.camera.to_tensor()
        sentai.tpu.invoke()
        sentai.aifes.from_tpu(0)    # set input from TPU output
        sentai.aifes.invoke()       # run AIfES inference
        probs = sentai.aifes.output()
        cls = probs.index(max(probs))
        print(f'Class {cls}: {probs[cls]:.2f}')

  Example (simple image classifier with from_camera):

    sentai.aifes.load('/models/mnist_mlp.yaml')  # input=784, output=10
    sentai.camera.init()
    
    # Real-time inference
    while True:
        sentai.aifes.from_camera(28, 28, True)  # 28x28 grayscale -> 784 floats
        sentai.aifes.invoke()
        probs = sentai.aifes.output()
        digit = probs.index(max(probs))
        print(f'Digit: {digit}')

  Example (simple audio classification with from_mic):
    # Train a sound classifier (1024 samples @ 16kHz = 64ms window)
    sentai.aifes.load('/models/sound_mlp.yaml')  # input=1024, output=3
    sentai.aifes.mic_init()  # Start microphone
    
    # Real-time inference

        sentai.aifes.from_mic(1024)  # 1024 samples -> 1024 floats [-1,1]
        sentai.aifes.invoke()
        probs = sentai.aifes.output()
        cls = ['quiet', 'speech', 'music'][probs.index(max(probs))]
        print(f'Sound: {cls}')

sentai.kmeans — K-Means Clustering for Embeddings
=================================================

Simple k-means clustering for classifying embedding vectors.
Ideal for few-shot learning: collect embeddings from TPU, 
cluster them, then classify new embeddings by nearest centroid.

No training required — just collect labeled samples and compute centroids.

  --- Setup ---
  init(k, dim) -> int   Initialize with k clusters and vector dimension.
                        Returns 0 on success.
                        k: 1-64, dim: 1-2048

  --- Manual Labeling (supervised) ---
  add(cluster_idx, vector) -> int
                        Add a vector (list of floats) to a specific cluster.
                        Use this for labeled training data.

  add_from_tpu(cluster_idx, tpu_idx) -> int
                        Add TPU output tensor directly to a cluster.
                        Auto-dequantizes int8/uint8 to float.

  compute() -> int      Compute centroids from added vectors.
                        Call after adding all training samples.

  --- Automatic Clustering (unsupervised) ---
  fit(max_iter=100) -> int
                        Run Lloyd's k-means algorithm on stored vectors.
                        Returns number of iterations.
                        Note: Use this AFTER adding vectors with add().

  --- Inference ---
  predict(vector) -> int
                        Predict cluster index (0 to k-1) for a vector.

  from_tpu(tpu_idx) -> int
                        Predict cluster using TPU output tensor.
                        The main entry point for inference.

  distances(vector) -> list
                        Get Euclidean distance to each centroid.

  --- Persistence ---
  save(path) -> int     Save centroids to file.
  load(path) -> int     Load centroids from file.
                        Automatically sets k and dim from file.

  --- Info ---
  centroid(idx) -> list Get centroid vector as list of floats.
  info() -> dict        Returns {k, dim, vectors, initialized, counts}
  clear() -> None       Clear training vectors (keep centroids).

  Example (few-shot image classifier with TPU backbone):
    # Use MobileNet as feature extractor (outputs 1280-dim embeddings)
    sentai.tpu.load('/models/mobilenet_v2_1.0_224_feature_vector_quant_edgetpu.tflite')
    sentai.camera.init()
    
    # Initialize k-means: 3 classes, 1280-dim embeddings
    sentai.kmeans.init(3, 1280)
    
    # Collect training samples (3 classes, 5 samples each)
    for label in range(3):
        print(f'Show class {label}, press Enter for each sample')
        for _ in range(5):
            input('Ready...')
            sentai.camera.to_tensor()
            sentai.tpu.invoke()
            sentai.kmeans.add_from_tpu(label, 0)  # Add embedding to cluster
    
    # Compute centroids
    sentai.kmeans.compute()
    sentai.kmeans.save('/models/my_classifier.kmeans')
    print(sentai.kmeans.info())  # {'k': 3, 'dim': 1280, 'vectors': 15, ...}
    
    # Inference loop
    while True:
        sentai.camera.to_tensor()
        sentai.tpu.invoke()
        cls = sentai.kmeans.from_tpu(0)
        dists = sentai.kmeans.distances(sentai.tpu.output_floats(0))
        confidence = 1.0 / (1.0 + dists[cls])  # Simple confidence metric
        print(f'Class {cls}: conf={confidence:.2f}')

  Example (unsupervised clustering of embeddings):
    # Collect unlabeled embeddings
    sentai.kmeans.init(5, 1280)  # 5 clusters, 1280-dim
    
    for i in range(100):
        sentai.camera.to_tensor()
        sentai.tpu.invoke()
        sentai.kmeans.add(0, sentai.tpu.output_floats(0))  # cluster 0 = placeholder
    
    # Run k-means to find clusters
    iters = sentai.kmeans.fit(50)  # max 50 iterations
    print(f'Converged in {iters} iterations')
    print(sentai.kmeans.info()['counts'])  # Samples per cluster
    sentai.kmeans.save('/models/clusters.kmeans')

  Key advantages over AIfES:
  - No training required (just centroid computation)
  - Works with any embedding dimension
  - Instant inference (single distance computation)
  - Perfect for few-shot scenarios (1-10 samples per class)

  Memory usage:
  - Centroids: k × dim × 4 bytes
  - Training vectors: up to 1000 × dim × 4 bytes (cleared after compute)
  - Example: 5 clusters × 1280 dim = 25.6 KB for centroids
