E5 — Camera switch round-trip latency.
Measures the cost of switching from one physical camera to another and getting the first fresh frame.

Columns:
  run_index                       : repetition number (0-based)
  camera_select_ms                : time for sentai.camera.select() call only
  wait_new_frame_plus_tensor_ms   : time to wait for a new frame from the new sensor + to_tensor()
  total_roundtrip_ms              : select + wait + tensor combined

Note: wait_new_frame dominates because the sensor needs to flush its pipeline.

Parameters:
  repetitions = 3
  from_cam = 0
  to_cam = 1
