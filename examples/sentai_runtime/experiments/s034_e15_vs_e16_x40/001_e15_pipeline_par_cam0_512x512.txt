E15 - Parallel inference pipeline, measured sustained FPS.
Uses firmware PrepTask (PXP+quant into staging) || InferTask
(memcpy staging->tensor, Invoke, NMS).  Staging buffer released
before Invoke runs, so frame N+1 prep overlaps with frame N invoke.

Columns:
  run_index          : frame index (0-based)
  frame_interval_ms  : wall-clock delta between consecutive pipeline.get()
                       = sustained loop time (lower is better)
  prep_stall_ms      : time since PrepTask last completed a frame (ms)
  infer_stall_ms     : time since InferTask last completed a frame (ms)
  num_detections     : detections returned for this frame

Sustained FPS = 1000 / mean(frame_interval_ms).

Parameters:
  height = 512
  conf = 0.25
  iou = 0.45
  max_det = 50
  model_path = /yolo_1_class_512_1_upsample_512_inloc_de_1024_la_P5_32.tflite
  frames_received = 40
  frames_timeouts = 0
  fw_processed = 41
  fw_dropped = 0
  repetitions = 40
  camera_id = 0
  width = 512
