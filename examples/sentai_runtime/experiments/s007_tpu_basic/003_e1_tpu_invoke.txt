E1 — EdgeTPU invoke latency.
Measures how long sentai.tpu.invoke() takes to run one forward pass on the EdgeTPU.

Columns:
  run_index          : repetition number (0-based)
  edgetpu_invoke_ms  : wall time of tpu.invoke() in milliseconds

Note: first run is warm-up and excluded. Subsequent runs use the same loaded model.

Parameters:
  model_path = /yolo26n.edgetpu_1.tflite
  repetitions = 10
  use_camera = True
  image_path = None
