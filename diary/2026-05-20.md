### CRITICAL clamp-bug discovery + W17 invalidation

Investigation: `m4_bench_host.cc:84-85` was clamping `block`
to `[3, 511]` BEFORE IPC send.  All sentinel values
(0xCAFE, 0xC100..C108, 0xF10F, 0xF1D7, 0xF1DD) > 511, so
ALL got smashed to 511, M4 worker received block=511 and
fell into the default ArUco-threshold path at block=511
(~25-29 ms) regardless of intended workload.

**Retroactively invalidated**:
- W17-T2 "M4 WhyCon Phase A 25.86 ms" → ArUco @ 511
- W17-T4 "M4 Flow SAD 26.51 ms / M7 wins 27×" → ArUco @ 511
- W17-T4 "M4 DTCM no diff" → both ArUco @ 511, same code
- W18 pre-fix "M4 diamond 25.93 ms = no help" → ArUco @ 511

Fix commit 5f34a8dc: clamp removed from host; HARD-RULE
captured in `[[ipc-clamp-in-worker-not-host]]` memory.

### Path from "Y MAE 17 cm" (iter-7) → "Y MAE 2 mm" (today)

Each error left a measurable scar.  In order of unwind:

1. **Detector duplicates** — Krajník centre dot + outer
   annulus are both dark blobs passing fill-ratio.  W3
   concentric check rejects the dot (`whycon_w3_check_` in
   sentai_aruco.cc, samples at 0.55·R / 0.95·R).
2. **ANNULUS_FACTOR** — outer-ring effective semi-axis from
   2nd-moment integration is `0.825·R` for r1/R=0.6.  PnP
   needs `1/0.825 = 1.166`.  Iter-3 had it at 1.0 (assumed
   PBR-smoothing; wrong).
3. **Z reflection ambiguity** — coplanar markers give
   Kabsch a 2-fold reflection.  Pick the one with drone
   above the marker plane.
4. **Time-matching off-by-7s** — verdict normalized sentai
   ticks and GT rows to zero before pairing.  Off by the
   takeoff-and-settle interval.  Fixed: pair by absolute
   host wall clock.
5. **Cam-body offset on X** — cf2 cam mounted at body
   (-0.04, 0, -0.02).  Pre-T5, Kabsch returned cam world
   position; verdict compared with drone body GT → constant
   -4 cm bias on X.  T5 internalises the offset.
6. **Mirror Kabsch ambiguity** — square 4-fold-symmetric
   layout permits 4 valid det=+1 Kabsch rotations.  Yaw-
   anchor picker disambiguates per-frame.
